# «Кәусар» бөбекжай балабақшасы — лендинг

Next.js 15 + TypeScript + Tailwind CSS 4.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Фотографии

Фото подхватываются из `public/images` автоматически (пока фото нет — показываются аккуратные заглушки):

| Путь | Где используется |
| --- | --- |
| `public/images/hero.jpg` | Главный экран (если нет — первое фото галереи) |
| `public/images/groups/balausa.jpg`, `baldyrgan.jpg`, `sultan.jpg` | Карточки групп (если нет — фото из галереи) |
| `public/images/food/*.jpg` | Блок «Тамақтану» (до 5 фото) |
| `public/images/daily/*.jpg` | Блок «Баланың әр күні» (если нет — фото из галереи) |
| `public/images/*.jpg` | Галерея — все остальные фото |

Поддерживаются `.jpg .jpeg .png .webp .avif`. Сортировка по имени с учётом чисел (`photo2` раньше `photo10`).
В галерее размер плитки подбирается по ориентации фото; по клику фото открывается целиком, без обрезки.
Если на каком-то фото обрезается голова — задайте точку фокуса в `imageOverrides` в `lib/images.ts`.

Страница статическая: после добавления фото на продакшене нужно пересобрать проект (`npm run build`).

## Данные

- Контакты, адрес, часы работы — `lib/site.ts`
- Тексты разделов (группы, преимущества и т.д.) — `lib/content.ts`
- Домен для SEO — переменная окружения `NEXT_PUBLIC_SITE_URL`
